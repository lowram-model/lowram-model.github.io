LowRAM

Why spend memory on what you can predict?

LowRAM compresses the KV cache used by long-context LLMs. It reconstructs values from their keys, keeps corrections for the hardest-to-predict values, and compresses keys across layers.

Base-model weights stay frozen. Lightweight predictors adapt to each prompt.

Up to26.9× KV-cache compression Retaining 94.5% of the uncompressed LongBench score LowRAM + quantisation + eviction

Compression: Mistral-7B, LongBench prompts longer than 10K tokens. Throughput: Llama-3.1-8B, comparing peak decode throughput across batch sizes. These are separate experimental settings.

4Try it yourself

Start with a small retrieval example, then measure the tradeoffs on your own workload.

Requirements: Python 3.12, a CUDA GPU, Git LFS and access to the selected model. The supplied demo supports Llama and Mistral. The default Llama model requires approved Hugging Face access.

Run the demo

Start with a 4K-token document and a 4× cache-compression target. Use the fast preset, then compare its answer with the uncompressed baseline.

Setup
git clone https://github.com/lowram-model/lowram
cd lowram
git lfs install
git lfs pull
conda create -n lowram python=3.12 -y
conda activate lowram
pip install -r requirements.txt

If needed, create or edit .env in the repository root and add HF_TOKEN="<your_huggingface_token>". Keep any existing settings and never commit this file.

Run the demo
# Fast LowRAM preset
python -m examples.lowram_demo --method fast

# Uncompressed baseline
python -m examples.lowram_demo --method baseline

The demo prints the question, reference codes, generated answer and fact-recall score. The fast preset uses meta-initialised value prediction, two fitting steps and selective reconstruction. Use --method lowram for the full-adaptation preset with more fitting steps.

Reproduce the larger benchmark

This runs the larger comparison and requires substantially more GPU memory than the introductory demo. Commands run from the repository root.

Benchmark comparison
python -m benchmarks.compare \
  --methods baseline fast lowram \
  --meta-weights checkpoints/meta_init/Llama-3.1-8B-Instruct/meta_mlps.pt \
  --contexts 131072 --batch-sizes 1 2 4 6 8 12 \
  --ratios 4 --samples 24 --repeats 2 --warmup 1 \
  --decode-tokens 48 \
  --output results/demo/comparison.json

The two scripts currently initialise the full-adaptation lowram preset differently: the small demo loads value-MLP warm-start weights, while this comparison script does not pass those weights. Treat their outputs as separate configurations, not identical reruns.
